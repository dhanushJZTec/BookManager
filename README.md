# 📚 Book Manager Console App

A simple C# console application to manage a list of books using collections and LINQ.

---

## 🚀 Features

- ➕ Add Book
- ❌ Remove Book
- 🔍 Search Book (by title)
- 🔃 Sort Books
- 📖 Display All Books
- ⚠️ Exception Handling (try-catch-finally)

---

## 🛠️ Technologies Used

- C#
- .NET Console Application
- Collections (`List<Book>`)
- LINQ
